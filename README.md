## 🌌 Overview

**SD-OS** is a unique, highly interactive web-based portfolio that simulates a classic command-line/desktop operating system environment right in your browser. Built with a responsive, mobile-first approach, it seamlessly merges nostalgic aesthetics with modern web technologies to showcase projects, skills, and professional experience.

Designed by an Ethical Hacker and Hardware Developer, the portfolio features:
- 💻 **Interactive Terminal:** Execute real commands (e.g., `help`, `whoami`, `contact`, `clear`) to discover hidden easter eggs and information.
- 🗂️ **Windowed UI:** Draggable, responsive windows containing case studies, career timelines, and a resume.
- 📱 **Mobile Responsive:** Perfectly adapted for mobile devices, ensuring the full OS experience is retained on smaller screens.
- 🔊 **Web Audio:** Programmatic synth sounds and boot sequences using the Web Audio API.

## 💻 Getting Started

To run the SD-OS portfolio locally:

### Prerequisites
- [Node.js](https://nodejs.org/) installed on your machine.

### Installation
1. **Clone the repository:**
   ```bash
   git clone https://github.com/Sunil56224972/SD-OS-MOBILE-RESPONSIVE.git
   cd SD-OS-MOBILE-RESPONSIVE
   ```

2. **Run a local server:**
   You can use any static file server. Using `serve` via `npx` is recommended:
   ```bash
   npx serve .
   ```

3. **View the site:**
   Open your browser and navigate to the localhost port provided by the server (usually `http://localhost:3000`).
